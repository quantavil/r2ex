# r2ex Dashboard (`r2ex-dashboard`)

Modern SvelteKit 2 + Svelte 5 (Runes) + Tailwind CSS v4 personal cloud web dashboard for `r2ex`.

## Development

```bash
# Install dependencies
bun install

# Run dev server
bun run dev

# Run unit tests
bun run test

# Type check & diagnostics
bun run check

# Build production SPA
bun run build
```
